# Herramientas digitales para documentar un proyecto

<p class="meta">Tecnología y Digitalización · 2º ESO · Digitalización</p>

## Definición

Para elaborar una memoria técnica con un formato claro y profesional usamos un **procesador de textos**: en el aula, **LibreOffice Writer**, software libre e instalado en todos los ordenadores del centro. Un documento bien formateado no es solo una cuestión estética: ayuda a que la información se entienda mejor y más rápido.

Las herramientas clave de Writer para documentar un proyecto son los **estilos**. Un estilo es un conjunto de características de formato (tipo y tamaño de letra, negrita, espaciado…) guardado con un nombre, que se puede aplicar a cualquier párrafo con un clic. En vez de formatear cada título "a mano", se le asigna el estilo "Título 1", "Título 2", etc. Esto tiene dos ventajas prácticas: si luego se cambia el estilo, cambian a la vez todos los párrafos que lo usan; y permite generar automáticamente una **tabla de contenidos** (el índice del documento), porque Writer sabe qué párrafos son títulos gracias al estilo aplicado, no a su aspecto.

Instalar y configurar el programa también forma parte de un uso responsable de las herramientas digitales: mantenerlo actualizado, guardar copias del trabajo en curso y usar formatos abiertos (.odt) que cualquiera pueda abrir, en vez de depender de un programa de pago.

## Clic.

Para poner una portada, un título de apartado y un subapartado en una memoria técnica: al título del proyecto se le aplica el estilo "Título", a "1. Objetivos" o "2. Proceso de fabricación" el estilo "Título 1", y a un subapartado dentro de ellos el estilo "Título 2". Con eso ya hecho, en *Insertar ▸ Tabla de contenidos* Writer genera solo el índice, con los números de página correctos y listos para actualizar si se añade una página más adelante.
