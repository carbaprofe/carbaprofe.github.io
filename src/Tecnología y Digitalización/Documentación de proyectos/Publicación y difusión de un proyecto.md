# Publicación y difusión de un proyecto

<p class="meta">Tecnología y Digitalización · 2º ESO · Digitalización</p>

## Definición

Documentar un proyecto no termina al guardar la memoria técnica: el último paso es **difundirla**, es decir, hacerla accesible a otras personas. Esto es útil por varias razones: para que otro grupo que vaya a abordar un proyecto parecido conozca de antemano su coste o sus dificultades, para que el profesorado pueda seguir el progreso del trabajo, o simplemente para compartir el resultado final.

Existen distintos tipos de herramientas digitales para esto, cada una pensada para una fase distinta:

- **Intercambio de archivos**: compartir un documento o una carpeta con el resto del grupo o con el profesorado (por ejemplo, a través del aula virtual).
- **Seguimiento del proceso**: un diario o bitácora donde se registran los avances a medida que ocurren (lo que en internet se conoce como *blog*).
- **Publicación de un sitio propio**: una página web sencilla donde se presenta el proyecto terminado, con texto e imágenes organizados por secciones.
- **Difusión del resultado final**: presentaciones o vídeos breves pensados para explicar el proyecto a un público que no ha seguido el proceso.

En clase, la parte práctica de la difusión se hace con las herramientas del centro (aula virtual, LibreOffice Impress para presentaciones); conviene, aun así, conocer que existen plataformas específicas para cada uno de estos usos, para poder reconocerlas si se encuentran fuera del aula.

## Clic.

Un ejemplo de por qué importa el orden: no tiene sentido grabar un vídeo de difusión (el resultado final) si todavía no existe una memoria técnica que explique el proceso — el vídeo se apoya en lo que ya está documentado, no lo sustituye.
