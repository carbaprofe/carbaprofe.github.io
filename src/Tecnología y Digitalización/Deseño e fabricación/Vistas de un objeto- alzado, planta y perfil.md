# Vistas de un objeto: alzado, planta y perfil

<p class="meta">Tecnología y Digitalización · 2º ESO</p>

## Definición

El sistema más empleado para representar objetos y piezas es el sistema de **proyecciones diédricas**. Es como si se iluminara el objeto con un foco y se dibujara la sombra que proyecta cada cara — cada uno de esos dibujos se llama **proyección ortogonal** o **vista**.

Las **vistas principales** de un objeto son el alzado, la planta y el perfil. El **alzado** es la vista principal: siempre la cara más representativa de la pieza, la que más información aporta (se suele señalar con una flecha en el objeto). La **planta** es la vista que se obtiene mirando el objeto desde arriba: imagina que, partiendo del mismo punto desde donde ves el alzado, te subes encima del objeto y miras hacia abajo. El **perfil** es la vista que se obtiene mirando el objeto desde un lado, normalmente el lado izquierdo.

Para representar un objeto se utilizan habitualmente solo las **tres vistas principales**: alzado, planta y uno de los dos perfiles (el que aporte más información). Su colocación en el papel sigue una regla fija: la planta se dibuja **debajo** del alzado, y el perfil se dibuja **a la derecha** o **a la izquierda** del alzado, alineado con él. Ten en cuenta que lo que ves desde arriba se dibuja debajo del alzado, y lo que ves a la izquierda se dibuja a la derecha — es decir, cada vista se coloca al revés de cómo la ves, porque son proyecciones, no fotografías.

## Clic.

Para representar las vistas de una figura, imagina que proyectas una luz sobre ella desde tres direcciones: de frente, desde arriba y desde un lado. La sombra que se proyecta en cada caso es la vista correspondiente — el alzado, la planta y el perfil.

Este ejercicio, el de "adivinar" las tres vistas de una figura en perspectiva (o al revés, reconstruir la perspectiva a partir de las tres vistas), es el tipo de ejercicio de vistas más habitual en digitalización — el mismo tipo de razonamiento espacial que se practica con un tangram: reconocer qué forma tridimensional generaría una silueta plana concreta.
