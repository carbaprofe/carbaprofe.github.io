# Seguridad en la red: riesgos y amenazas

<p class="meta">Tecnología y Digitalización · 2º ESO · Digitalización</p>

## Definición

El **malware** (software malicioso) es cualquier programa diseñado para dañar un dispositivo o robar información sin permiso del usuario. Tiene varios tipos: el **virus** se replica infectando otros archivos; el **troyano** se disfraza de programa legítimo para colarse en el sistema; el **ransomware** bloquea el acceso a los archivos hasta que se paga un rescate; el **spyware** espía la actividad del usuario sin que este lo note.

El **phishing** es un engaño que busca que la víctima entregue información confidencial (contraseñas, datos bancarios) haciéndose pasar por una entidad de confianza — normalmente por correo electrónico o mensaje. Se reconoce por direcciones sospechosas, saludos genéricos, lenguaje urgente y enlaces a páginas que imitan a las reales.

Para protegerse, las medidas básicas son: mantener el sistema y los programas actualizados, usar un antivirus, usar **contraseñas seguras** (largas, con combinación de mayúsculas, minúsculas, números y símbolos, distintas para cada servicio), y desconfiar de enlaces o archivos adjuntos de origen desconocido.

## Clic.

Antes de hacer clic en un enlace de un correo o mensaje inesperado, tres comprobaciones rápidas: ¿el remitente es quien dice ser (o es una dirección extraña)? ¿el mensaje transmite urgencia o amenaza para que actúes sin pensar? ¿el enlace, al pasar el ratón por encima sin hacer clic, lleva realmente a la web que dice? Si algo falla en cualquiera de las tres, lo más seguro es no hacer clic y consultarlo con un adulto o con el profesorado.
