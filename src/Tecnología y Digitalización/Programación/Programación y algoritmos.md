# Programación y algoritmos

<p class="meta">Tecnología y Digitalización · 2º ESO · Digitalización</p>

## Definición

Un **algoritmo** es una secuencia ordenada de pasos que resuelve un problema o realiza una tarea concreta. No hace falta un ordenador para tener un algoritmo: una receta de cocina o las instrucciones para montar un mueble también lo son, porque describen, paso a paso y sin ambigüedad, qué hay que hacer y en qué orden.

**Programar** es traducir un algoritmo a un **lenguaje de programación**, es decir, a un conjunto de instrucciones que un ordenador puede entender y ejecutar. Cada instrucción (también llamada **comando**) le indica al ordenador una acción concreta; el conjunto de instrucciones escritas para resolver una tarea es el **código** o **programa**. Para que un algoritmo funcione como programa, cada paso tiene que ser preciso: un ordenador no "sobreentiende" nada que no esté escrito explícitamente.

## Clic.

Antes de programar nada, conviene describir el algoritmo con palabras normales. Por ejemplo, para que un robot cruce una habitación esquivando una silla: "1) avanza hasta detectar un obstáculo, 2) gira a la derecha, 3) avanza de nuevo, 4) gira a la izquierda para volver a la dirección inicial, 5) sigue avanzando." Solo después de tener claros estos pasos tiene sentido convertirlos en bloques o código.
