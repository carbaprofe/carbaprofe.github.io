# Estructuras de control: secuencial, condicional y repetitiva

<p class="meta">Tecnología y Digitalización · 2º ESO · Digitalización</p>

## Definición

Todo algoritmo se puede construir combinando solo tres tipos de estructura:

La **estructura secuencial** es la más simple: las instrucciones se ejecutan una detrás de otra, en el mismo orden en que están escritas, sin saltos ni repeticiones.

La **estructura condicional** introduce una **condición**: el programa comprueba si algo se cumple (por ejemplo, "¿el valor de una variable es mayor que 10?") y, según el resultado, ejecuta un bloque de instrucciones u otro distinto. Es la estructura que representa el rombo en un [[Diagramas de flujo|diagrama de flujo]].

La **estructura repetitiva** (o **bucle**, en inglés *loop*) ejecuta el mismo bloque de instrucciones varias veces, mientras se cumpla una condición o un número determinado de veces. Evita tener que escribir la misma instrucción una y otra vez.

Una **variable** es un espacio con nombre donde un programa guarda un valor (un número, una palabra, un resultado) que puede cambiar mientras el programa se ejecuta; las estructuras condicionales y repetitivas casi siempre comprueban el valor de una variable para decidir qué hacer.

## Clic.

Para que un personaje de un juego dé tres pasos y luego salte si encuentra un obstáculo: los tres pasos son una **estructura secuencial** (o, mejor aún, una **repetitiva** que repite "avanzar" tres veces); comprobar si hay un obstáculo y decidir si saltar es una **estructura condicional**.
